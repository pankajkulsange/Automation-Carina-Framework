# Automation-Carina-Framework
This repository contains an automation testing framework built with Java, Selenium, TestNG, Cucumber, Carina Framework, and Maven. The framework is designed for web application testing, providing a scalable and maintainable solution for automated testing.

## Technologies Used
- **Java**: Core programming language
- **Selenium**: Web automation tool for browser interaction
- **TestNG**: Testing framework for running and managing tests
- **Cucumber**: BDD (Behavior Driven Development) tool for writing human-readable tests
- **Carina Framework**: Provides support for Web, API, and Mobile testing
- **Maven**: Build automation tool for dependency management and project structure

## Features
- Web UI Automation with Selenium
- Behavior-Driven Development (BDD) with Cucumber
- Parallel test execution using TestNG
- Reporting and logging
- Carina Framework integration for enhanced automation capabilities
- Page Object Model (POM) design pattern
- Cross-browser testing support
- Maven-based dependency management

## Prerequisites
Before running the tests, ensure you have the following installed on your machine:
- **Java 8+**
- **Maven**: For building and managing the project dependencies
- **ChromeDriver** / **GeckoDriver** (for Chrome/Firefox browser automation)
- **IDE**: IntelliJ IDEA, Eclipse, or any Java IDE of your choice
